# Moments

Студия записи экрана и видеомонтажа для Windows 11 x64. Moments записывает экран, окно или выбранную область, сохраняет последние 5–10 минут игры по горячей клавише и позволяет редактировать клипы. Звук игры, Discord и других приложений можно записывать на отдельные дорожки.

**[Скачать Moments для Windows x64](https://github.com/drdredd007/ScreenCapture/releases/latest)** — выберите ZIP в разделе **Assets**.

## Запуск

1. Установите **.NET Desktop Runtime 10 x64**, если он ещё не установлен.
2. Распакуйте ZIP целиком в папку, в которую у вас есть право записи. FFmpeg и FFprobe уже входят в комплект.
3. Запустите `Moments.exe`. Видео, монтажные проекты и настройки сохраняются рядом с программой.

## Запись и игровые повторы

На странице **Capture** выберите экран, окно или область. Для области выберите дисплей, нажмите **Select region** и растяните рамку мышью. Клавиша `Esc` отменяет выделение. Для записи окна выберите его заголовок. Кнопка **↻** обновляет список.

Нажмите **Start recording**. Остановить запись можно в студии или через значок Moments в трее. Клип появится в **Library**, где новые записи находятся сверху. Если при сохранении MP4 произошла ошибка, Moments сохраняет исходную запись в MKV.

### Как сохранить последние минуты игры

1. В **Settings → Add game** выберите запущенное окно, укажите файл игры или вставьте полный путь к нему. Если у игры есть лаунчер, выберите процесс с игровым окном.
2. Включите автоматический буфер и выберите **5 или 10 минут**. Оставьте Moments открытым или сверните в трей. При запуске выбранной игры индикатор **Buffer** покажет время накопления.
3. Нажмите `Ctrl+Shift+F8`, чтобы сохранить повтор. Пока буфер заполняется, сохранится уже записанная часть. Во время сохранения запись продолжается.

Чтобы назначить своё сочетание, нажмите текущий хоткей в **Settings → Save replay**, затем нажмите и отпустите новые клавиши. Клавиша `Esc` отменяет ввод.

При закрытии игры буфер останавливается. Ручная запись временно занимает захват. После её остановки Moments снова проверяет запущенные игры. Команда **Exit** в трее завершает программу.

### Автосохранение событий League of Legends

В **Settings → League of Legends Auto-Save** включите автосохранение и выберите события: собственные убийства, смерти, ассисты, дабл/трипл/квадра/пентакиллы, участие в убийстве дракона, Барона и Герольда, а также собственные кражи этих объектов. По умолчанию включены убийства, мультикиллы и кражи объектов.

Добавьте **League of Legends.exe** из папки `Game` в список игр и включите автоматический буфер. Лаунчер `LeagueClient.exe` не подходит. Во время матча Moments читает официальный локальный Live Client Data API; отдельный облачный ключ API не нужен.

После выбранного события начинается ожидание **30 секунд**. Каждое новое выбранное событие начинает отсчёт заново. По истечении задержки сохраняются последние **5 или 10 минут на момент сохранения** — согласно настройке активного буфера. Если буфер ещё не заполнился, сохраняется доступная часть. Изменение длины применяется со следующего запуска буфера.

В затяжном бою программа сохраняет промежуточный повтор до того, как первое событие выйдет из буфера; последующие события запускают следующий повтор. При остановке буфера или выходе из игры ожидающий повтор сохраняется сразу, без оставшихся 30 секунд. При ошибке сохранения выполняется повторная попытка; если буфер приходится остановить, несохранённые исходные сегменты остаются в `Cache`, а путь выводится в уведомлении и журнале.

События, уже произошедшие до первого подключения или повторного включения функции, не запускают старые повторы. Автосохранение относится только к активному игроку. Неоднозначные имена без тега пропускаются. Состояние подключения и обратный отсчёт показаны на странице Capture и в настройках.

Рядом с автоклипом сохраняется файл `.events.json`. Он содержит метки событий, доступные на видеодорожке и в разделе **Game Events** редактора. При переносе клипа сохраняйте этот файл рядом с видео. Время меток приблизительное из-за опроса игрового API.

### Виды библиотеки

На странице **Library** переключатель **List / Tiles** выбирает компактный список или сетку крупных превью. Вид сохраняется между запусками. Поиск, порядок от новых к старым и группировка по датам одинаковы в обоих режимах. Нажатие на запись открывает редактор; количество колонок плиток зависит от ширины окна.

### Звук приложений и микрофона

В **Settings → Audio Tracks** включите **System audio** и **Separate app tracks**. Разделение включено по умолчанию. В запись или повтор попадёт отдельная стереодорожка каждого приложения, которое воспроизводило звук в сохранённом отрезке. Приложения можно открывать и закрывать во время записи. Микрофон включается отдельно.

**Как убрать Discord и оставить игру.** Откройте клип в **Library**, снимите отметку **Discord** рядом с его звуковой волной и нажмите **Export**. В многодорожечном редакторе кнопка **M** на дорожке отключает её в предпросмотре и при экспорте.

Moments определяет приложения по аудиосессиям Windows. Несколько экземпляров одного исполняемого файла объединяются в одну дорожку. Если нужен общий звук устройства, включая системные сигналы без приложения, выключите **Separate app tracks** до следующей записи. В старых записях с одной дорожкой **System** голоса и игра уже смешаны. Обычный видеоплеер может по умолчанию воспроизводить только первую дорожку.

### Профили качества

| Профиль | Максимальное разрешение | Кадры/с | Битрейт видео |
| --- | --- | ---: | ---: |
| Compact | 1280 × 720 | 30 | 4 Мбит/с |
| Standard | 1920 × 1080 | 60 | 10 Мбит/с |
| High | 2560 × 1440 | 60 | 18 Мбит/с |

Moments сохраняет пропорции источника. Небольшие окна остаются в исходном размере с округлением до чётных размеров. На совместимых видеокартах NVIDIA используется NVENC. Для очень маленьких областей или при недоступности NVENC используется x264. Профиль, источники звука и длину буфера выбирайте перед захватом.

Десять минут при 10 Мбит/с занимают около 750 МБ видео. На каждое непрерывно звучащее приложение понадобится ещё около 110 МиБ временного места в `Cache`. Итоговые дорожки сохраняются в AAC. Для сохранённой копии повтора потребуется дополнительное место.

## Монтаж

### Обрезать один клип

1. Откройте запись в **Library**. Перетащите границы A и B на видеодорожке или поставьте их клавишами `A` и `B` по текущей позиции.
2. Нажмите **Cut A–B**, чтобы вырезать интервал, или **Keep only A–B**, чтобы обрезать края. Повторите для остальных фрагментов. Для восстановления выберите удалённый интервал и нажмите **Restore selected cut**.
3. Нажмите `Пробел` для просмотра. Отметьте звуковые дорожки, которые хотите сохранить. Они экспортируются раздельно. Если снять все отметки, получится видео без звука.
4. Укажите название, выберите **MP4 (H.264)**, **MKV (H.264)** или **WebM (VP9)** и нажмите **Export**. Готовый клип появится в библиотеке. Исходная запись сохранится.

### Собрать видео из нескольких клипов

Откройте **Video Editor** и перетащите клип из библиотеки слева на **V1** или **V2**. Двойной щелчок добавляет его в конец монтажа. Для внешних файлов используйте **+ Import** или перетащите их из Проводника. Импортированный файл должен оставаться по исходному пути. В редакторе отдельного клипа кнопка **Add source to timeline** добавляет исходную запись в конец проекта.

| Действие | Управление |
| --- | --- |
| Перейти к нужному моменту | Нажмите или тяните мышью по линейке времени над дорожками. |
| Переместить или обрезать фрагмент | Тяните середину для перемещения, край для обрезки. Видео и связанный с ним звук двигаются вместе. Кнопка **Unlink** снимает связь. |
| Состыковать клипы | Подведите край одного к краю другого, в том числе на соседней дорожке. Золотая линия отмечает стык. Удерживайте `Alt` для свободного перемещения. |
| Разрезать фрагмент | Нажмите `S` над фрагментом для разреза под мышью. Вне дорожек `S` режет выбранную дорожку по плейхеду. Чтобы выбрать дорожку, нажмите её заголовок слева. |
| Удалить фрагмент | Нажмите `Delete`. Связанный с ним отрезок звука также удалится. |
| Просмотреть и уточнить позицию | `Пробел` запускает просмотр, стрелки перемещают позицию на кадр. |
| Отменить или вернуть правку | `Ctrl+Z` и `Ctrl+Y`. Команду **Clear**, очищающую таймлайн, тоже можно отменить. |

При наложении клипов видно верхнюю занятую видеодорожку. Звук клипа автоматически раскладывается по свободным аудиодорожкам. Перетащите клип прямо на аудиодорожку, чтобы добавить только звук. В пустых интервалах без активных дорожек будут чёрный кадр и тишина.

Черновик сохраняется автоматически в `Projects\current.json`. Готовый монтаж экспортируется в `Videos\Монтаж` со стереомиксом включённых дорожек. Разрешение и частота кадров проекта задаются первым роликом. Для RGB-предпросмотра действуют пределы 1280 × 720 и 30 кадров/с. Покадровая навигация и экспорт используют частоту проекта.

## Сборка из исходников

Понадобятся Windows x64, .NET 10 SDK и Git LFS. После клонирования репозитория выполните в PowerShell из его корня:

```powershell
git lfs pull
.\build.ps1
```

Скрипт поместит `Moments.exe` в корень проекта. Git LFS загружает версии FFmpeg и FFprobe, с которыми работает приложение.

| Путь | Содержимое |
| --- | --- |
| `Videos\` | Записи и игровые повторы |
| `Videos\Монтаж\` | Результаты экспорта |
| `Projects\` | Черновик монтажа |
| `Cache\` | Рабочий буфер, временные файлы и миниатюры |
| `settings.json` и `Moments.log` | Настройки со списком игр и журнал диагностики |
| [src](src) и [build.ps1](build.ps1) | Исходный код и скрипт сборки |
| [tests](tests) | Проверки интерфейса, монтажа и раздельной записи звука |


GitHub Actions также проверяет эти сценарии, собирает приложение и публикует новую версию из `main`, если такого релиза ещё нет. Проверки API используют сохранённые примеры ответов, а не живой матч. Для проверки на реальном клиенте включите нужные события, сыграйте тренировочную игру и убедитесь, что таймер начинается/продлевается только от своих выбранных событий, а повтор появляется через 30 секунд после последнего события.

### Синхронизация звука (1.1.1)

Исправлено отставание звука из-за разных точек начала аудио и видео. Системный звук, микрофон, дорожки приложений, видео и метки событий теперь используют общую временную шкалу. Время доставки PCM в FFmpeg и задержка уведомления о первом закодированном кадре не сдвигают дорожки. Видеочасы привязываются один раз перед обработкой кадра, затем сохраняют монотонные интервалы Windows Graphics Capture. Уже записанные файлы автоматически не исправляются.

Windows CI воспроизводит старый рассинхрон при задержанном старте видео и измеряет смещение между вспышками и звуковыми импульсами в декодированных MKV/MP4, включая отдельные дорожки приложений и повторы со склейкой сегментов. Эта синтетическая проверка не заменяет проверку конкретного аудиоустройства и игры на ПК. Отчёт: `av-sync-verification.txt` в артефакте `feature-ui-checks`.

### Плавность видео и обновления (1.1.2)

Видео захватывается в отдельном графе FFmpeg. Звук передаётся через PCM WAV-поток с пакетами по 480 отсчётов (10 мс), вместо неуправляемого накопления 4096 отсчётов в raw PCM-демультиплексоре. Ожидание порции PCM-звука больше не останавливает получение кадров Windows Graphics Capture. Системный звук, микрофон и отдельные приложения сохраняют общую временную шкалу с видео. Это устраняет источник повторяющихся кадров в файлах, которые формально записаны с частотой 60 FPS.

Проверка плавности в Windows CI подаёт звук в реальном времени через named pipe и записывает изображение с меняющимся по часам идентификатором кадра. Она сравнивает реальное количество изменений между старым общим и новыми независимыми графами, а также проверяет сохранённый MP4. Отчёт `video-cadence-verification.txt` находится в артефакте `feature-ui-checks`. Проверки синхронизации звука продолжают выполняться с новыми графами. Производительность конкретной игры, GPU и устройства захвата проверяется на реальном ПК.

В **Settings → Updates**:

1. **Check for updates** проверяет последний стабильный релиз `drdredd007/ScreenCapture` и сравнивает номер с установленной версией.
2. **Download update** скачивает Windows x64 ZIP в папку `Updates` рядом с Moments. Отображается прогресс, загрузку можно отменить.
3. Архив становится доступным после проверки размера и SHA-256 по контрольной сумме релиза. При сбое или отмене незавершённый файл удаляется; ранее успешно скачанный архив сохраняется.
4. **Open download folder** открывает папку. Для установки полностью закройте Moments (включая трей), распакуйте ZIP в текущую папку приложения с заменой файлов и запустите его снова. Сохраняйте папки `Videos`, `Cache` и файл `settings.json`.

Проверка запускается по кнопке; скачивание не прерывает запись. Приложение не устанавливает обновление самостоятельно. Кнопка **Release notes** открывает описание релиза. Ошибки сети и лимит запросов GitHub отображаются рядом с кнопками; авторизация GitHub не требуется для публичного репозитория.
