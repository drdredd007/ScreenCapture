MOMENTS
Студия записи и монтажа для Windows 11 x64

Запуск
Распакуйте ZIP из GitHub Releases в папку с правом записи и откройте Moments.exe. Записи, проекты и настройки сохраняются рядом с программой. Для запуска нужен .NET Desktop Runtime 10 x64. FFmpeg и FFprobe уже включены в архив.
Готовая сборка: https://github.com/drdredd007/ScreenCapture/releases/latest

Сборка из исходников
Для сборки нужны Windows x64, .NET 10 SDK и Git LFS. Из корня клонированного репозитория выполните:
  git lfs pull
  .\build.ps1
Скрипт соберёт Moments.exe в корне проекта. В tools находятся точные версии FFmpeg и FFprobe, используемые приложением.

Запись
На странице «Capture» выберите экран, окно или область. Для области сначала выберите дисплей, затем нажмите «Select region» и протяните прямоугольник. Esc отменяет выделение. В режиме окна выберите нужный заголовок. Кнопка ↻ обновляет список.
Нажмите «Start recording». Остановить запись можно в студии или из контекстного меню значка в трее. Видео появится в библиотеке. Если сборка MP4 не удалась, программа сохраняет исходную запись в MKV.

Игровые повторы
1. Откройте «Settings» и нажмите «Add game». Можно выбрать запущенное окно, найти .exe на диске или вставить его полный путь. Для игры с лаунчером выберите процесс с игровым окном.
2. Включите автозахват и выберите 5 или 10 минут. Оставьте Moments открытым или сверните его в трей. После запуска игры индикатор «Buffer» показывает время работы.
3. По умолчанию Ctrl + Shift + F8 сохраняет повтор. Чтобы назначить свои клавиши, нажмите текущее сочетание в настройках под «Save replay», затем нажмите и отпустите новое. Esc отменяет ввод. Во время накопления сохраняется доступная часть, после заполнения — последние 5 или 10 минут. Сохранение может занять несколько секунд. Игровой буфер продолжает работать.
4. При закрытии игры буфер останавливается. Ручная запись временно занимает захват. После её остановки Moments снова проверяет запущенные игры. Команда «Exit» завершает программу.

Звук приложений
В Settings → Audio Tracks включите System audio и Separate app tracks. Последний параметр включён по умолчанию, в том числе при обновлении. В обычной записи и игровом повторе Moments автоматически создаёт отдельную стереодорожку для каждого приложения, которое воспроизводило звук в сохраняемом отрезке. Приложения можно запускать и закрывать во время записи. Микрофон включается отдельно.
Чтобы убрать голоса из Discord, откройте клип в Library, снимите отметку Discord рядом со звуковой волной и нажмите Export. В Video Editor дорожки подписаны именами приложений, кнопка M заглушает дорожку в просмотре и экспорте. Несколько экземпляров одного исполняемого файла объединяются под одним именем. В обычном видеоплеере может по умолчанию воспроизводиться только первая аудиодорожка.
Разделение использует доступные аудиосессии процессов Windows. Для общего звука выбранного в Windows устройства, включая системные сигналы без приложения, выключите Separate app tracks. Настройка применяется со следующего запуска захвата. В прежних записях с дорожкой System голоса и игра уже смешаны.
Рабочие файлы отдельных приложений находятся в Cache. На 10 минут непрерывного звука одного приложения требуется около 110 МиБ временного места плюс видео. В итоговый файл дорожки записываются в AAC.

Профили
Compact    до 1280 × 720, 30 кадров/с, 4 Мбит/с
Standard     до 1920 × 1080, 60 кадров/с, 10 Мбит/с
High      до 2560 × 1440, 60 кадров/с, 18 Мбит/с
Соотношение сторон источника сохраняется. Меньшие источники остаются в исходном размере с округлением до чётных размеров. На совместимых устройствах NVIDIA используется NVENC. Для очень маленьких областей и при недоступности NVENC используется x264. Профиль, состав звука и длина буфера задаются перед началом захвата.
Ориентир для десятиминутного буфера при 10 Мбит/с — около 750 МБ видео плюс звук. Для сохранённой копии нужно дополнительное место.

Монтаж
На странице «Library» свежие записи расположены сверху. Нажмите на запись, чтобы открыть редактор.
Перетащите бирюзовые границы A и B на видеодорожке или задайте их кнопками по позиции ползунка. «Cut A–B» убирает выбранный интервал. «Keep only A–B» обрезает края. Повторите для остальных фрагментов. Чтобы восстановить интервал, выделите его в списке справа и нажмите «Restore selected cut».
Пробел запускает просмотр оставшихся фрагментов. Клавиши A и B ставят метки. Под видео видна форма сигнала каждой аудиодорожки. Отметки слева от дорожек включают их в просмотр и экспорт. Снятие всех отметок даёт видео без звука. При выборе обеих дорожек они сохраняются отдельно.
Укажите название и формат — MP4 (H.264), MKV (H.264) или WebM (VP9). Нажмите «Export». Результат появится в библиотеке, исходный клип сохранится.

Многодорожечный видеомонтаж
Откройте «Video Editor» в левой панели. Сверху слева находятся записи Moments. Кнопка «+ Import» добавляет внешние ролики по ссылке на файл. Можно также перетащить файлы из Проводника. Из быстрого редактора кнопка «Add source to timeline» добавляет исходную запись в конец текущего проекта.
Перетащите ролик на V1 или V2. Двойной щелчок по ролику в библиотеке добавляет его в конец. Верхняя из занятых видеодорожек видна в предпросмотре. Звук автоматически раскладывается по свободным аудиодорожкам. При переносе прямо на аудиодорожку добавляется только звук.
Тяните середину фрагмента для переноса и край для обрезки. Края притягиваются к границам других клипов, в том числе на соседних дорожках. На стыке появляется золотая линия. Удерживайте Alt для свободной подгонки. Видео и звук двигаются и обрезаются вместе. Кнопка «Unlink» снимает связь. Delete удаляет выбранный фрагмент и связанный с ним отрезок звука. Пустое место даёт чёрный кадр и тишину при отсутствии других активных дорожек.
Клавиша S над фрагментом разрезает только его под мышью. Вне дорожек S разрезает выбранную дорожку по плейхеду. Нажмите V1, V2, A1 или другой заголовок слева, чтобы выбрать дорожку. Для перемотки щёлкните или тяните мышью по линейке времени над дорожками. Пробел запускает просмотр, стрелки перемещают позицию на кадр, Ctrl+Z и Ctrl+Y отменяют и возвращают правки.
Черновик автоматически сохраняется в Projects\current.json. «Clear» освобождает таймлайн, действие можно отменить. Кнопки M заглушают отдельные дорожки в предпросмотре и экспорте. Готовый монтаж сохраняется в Videos\Монтаж с общим стереомиксом включённых дорожек. Размер и частота кадров проекта определяются первым роликом. RGB-предпросмотр ограничен 1280 × 720 и 30 кадрами/с. Покадровая навигация использует частоту проекта, экспорт выполняется в его разрешении и частоте.

settings.json — настройки и список игр
Moments.log — сообщения диагностики
src и build.ps1 — исходный код и сборка с помощью .NET 10 SDK
tests\ui-smoke.ps1 — проверка интерфейса с изолированным тестовым приложением
build\verification.txt и build\ui-verification.txt — результаты проверок
